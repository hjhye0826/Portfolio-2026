## 프로젝트 개요
PC 어드벤처 / 방 진행형 퍼즐 / 키보드 + 마우스
방 진입 → 기믹 파악 → 근접 상호작용 → 문 개방 → 다음 방의 흐름을 반복

## 개발 목표
1. Claude를 MCP로 Unity 에디터에 직접 연동한 AI 협업 워크플로우 경험
상호작용 시스템과 방 진행형 퍼즐 기믹을 직접 설계하고 AI와 함께 구현
기본 상호작용 설계와 규칙 설계 후 실제 기믹 개발을 AI에게 일임

2. 실무에서 개발한 튜토리얼 시스템의 TutorialManager에서 개선하고 싶던 점을 개선
기존의 TutorialManager에서 다 하던 일을 Tutorial 클래스로 분리해 개선
